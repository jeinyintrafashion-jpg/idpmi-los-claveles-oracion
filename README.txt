IDPMI LOS CLAVELES ORACIÓN — PRIMERA VERSIÓN
================================================

Qué contiene
- index.html: formulario móvil con Mateo 11:28.
- logo.png: logo recortado de la imagen que compartiste.
- manifest.webmanifest y sw.js: base para instalar como PWA.

IMPORTANTE
Esta es la primera maqueta del sitio. El formulario NO guarda datos todavía.
No publiques ni uses el formulario para recoger peticiones reales hasta conectar y probar una base de datos segura. Los datos incluyen información personal y posiblemente sensible.

Publicar gratis (opción sencilla)
1. En una computadora, abre https://github.com/ y crea una cuenta gratis.
2. Crea un repositorio nuevo, por ejemplo: idpmi-los-claveles-oracion.
3. Sube los cuatro archivos de esta carpeta a la raíz del repositorio.
4. En el repositorio, abre Settings > Pages.
5. En “Build and deployment”, elige “Deploy from a branch”, selecciona “main” y “/(root)”, y guarda.
6. GitHub te dará un enlace HTTPS. Espera a que termine la publicación.
7. Abre el enlace en Chrome en Android y usa el menú ⋮ > “Instalar aplicación” o “Añadir a pantalla de inicio”.
La publicación gratuita puede requerir una cuenta y los menús pueden variar. GitHub Pages es alojamiento estático: no es la base de datos.

Para guardar peticiones
Necesitamos conectar un backend seguro antes de utilizar el formulario. No pongas claves secretas en index.html. El siguiente paso recomendado es configurar una base de datos con plan gratuito y reglas de acceso:
- escritura pública únicamente para crear peticiones válidas;
- lectura, cambios de estado y administración solo para cuentas autorizadas;
- fecha/hora generada por el servidor;
- política de privacidad y consentimiento claro.
El formulario ya tiene el campo ENDPOINT vacío intencionalmente. No lo rellenes con una URL improvisada. Cuando estés listo, te guiaré para configurar el backend y probarlo sin usar datos reales.

QR
Cuando tengas el enlace HTTPS final, se puede generar un QR gratuito que apunte a ese enlace. No imprimas un QR definitivo antes de confirmar que el formulario publicado funciona.

Seguridad
- No uses una hoja o base de datos pública para datos de oración.
- Limita el acceso a los responsables necesarios.
- Recoge solo la información necesaria; considera si es indispensable pedir dirección exacta.
- Nunca uses datos de personas reales para probar la maqueta.
